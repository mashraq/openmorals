In three points:

1. **Proof comes before breadth.** A live run on a real host, an outside test corpus, a measured ask rate and a first release come before more guards, packs or hosts.
2. **Start with the undo net on Claude Code, then the merge check.** The merge check reads any agent's change, wherever it was written, including agents no local hook reaches.
3. **Model-independent, host-dependent; bounded spend, not a savings claim.** Say what each host honours, stop runaway trees at zero tokens per check, and publish a savings figure only from a measured run.
